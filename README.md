# 💻 Configuración de Entorno de Desarrollo en Windows

![Banner Configuración Windows](https://raw.githubusercontent.com/JosueSay/ImageDocs/main/WindowsDevelopmentSetup/banner.png "Banner Configuración Windows")

🔗 **Enlace del curso:** [Configuración de Entorno de Desarrollo en Windows](https://platzi.com/cursos/configuracion-windows/ "Ir al curso")

## 📌 Contenidos Principales

1. ### 🛠️ **Introducción a la Configuración de Entorno en Windows**

   Aprende a preparar Windows para desarrollo profesional. Conoce las herramientas esenciales para iniciar en programación y desarrollo web.

2. ### 🌐 **Herramientas para la Web y Desarrollo**

   Instala y configura navegadores, DevTools, VSCode y extensiones clave para optimizar tu flujo de trabajo.

3. ### 🐧 **Uso de Linux dentro de Windows (WSL & Máquinas Virtuales)**

   Domina Windows Subsystem for Linux, instala distribuciones como Ubuntu y aprende a manejarlas desde la terminal. Configura máquinas virtuales con VirtualBox para entornos alternativos.

4. ### 📦 **Instalación de Node.js y Python**

   Configura tus primeras herramientas de programación. Aprende a instalar y ejecutar Node.js, npm y Python dentro de Windows o WSL.

5. ### 🔧 **Git y GitHub desde Windows/WSL**

   Configura GitHub, crea tu llave SSH, gestiona proyectos con Git y aprende a trabajar profesionalmente desde la terminal.

6. ### ⚡ **Trucos y Productividad en Windows**

   Mejora tu experiencia con PowerToys y aprende configuraciones útiles para potenciar tu productividad como desarrollador.
